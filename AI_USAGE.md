# AI Usage Disclosure

AI assistants were used as development support during DATA 266 Lab 2.

## Uses of AI assistance

The team used AI assistance for:

* Explaining unfamiliar code and machine learning concepts.
* Debugging Python, PyTorch, Diffusers, Kaggle, and Git issues.
* Suggesting improvements to notebook organization and repository structure.
* Reviewing file paths, output organization, and documentation.
* Helping draft README files, contribution documentation, and submission links.
* Reviewing errors and proposing testable fixes.

## Human responsibility

All final implementation decisions were made and reviewed by the team members.

The team members:

* Ran the notebooks and scripts themselves.
* Reviewed generated outputs and evaluation files.
* Verified the repository contents.
* Checked the final submission files.
* Confirmed the reported metrics and results from actual runs.

AI assistance was not used to fabricate metrics, evaluation results, Kaggle scores, model outputs, or citations.

## Model and tool usage

Part 1 used the team's multimodal RAG implementation.

Part 2 used Stable Diffusion and LoRA fine tuning with the documented dataset and base model.

Part 3 used the implemented multi agent workflow and its documented evaluation scenarios.

AI assistants supported development and documentation, but the reported experimental results came from the executed notebooks and scripts.

## Privacy and security

The team did not provide private credentials, API keys, passwords, or authentication tokens to AI assistants.

Links to external services and model repositories are documented separately in `links.txt`.
